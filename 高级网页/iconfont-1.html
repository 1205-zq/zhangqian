字体图标 · Font-based

Font Awesome 以 Web Font 的形式分发：每个图标是字体里的一个字形（glyph）， 通过 CSS 的 :before { content: "\fxxx" } 映射到类名（如 .fa-palette）。

好处：矢量、任意缩放、可继承 color / font-size、 可配合 :hover 动画。本项目 CSS + woff2 字体已本地化到 ./cdn/fontawesome/，无需外链即可运行。
