让 AI 听懂需求：Swiper 四条配置的两轮迭代

本页记录任务一的完整过程：第一轮用「随口说」的提示词让 AI 生成代码，第二轮把需求拆成可判定的四条再问一次， 最后逐项在页面里验证。可验证页面：swiper-wySw4.html。

作者：张乾 建立时间：2026-11-11 模型：DeepSeek-V4.1-Flash Swiper 11.0.3（本地离线）

需任务要求：Swiper('#wySw4', {…})

  1. 无缝循环：最后一张之后直接回到第一张，没有空白和卡顿。
  2. 3.2 秒自动翻页，并且手动操作（拖动、点箭头、点圆点）之后不停止。
  3. 圆点分页器可以点击，点了直接跳到对应页。
  4. 初始效果就是 cube（立方体），不是默认的 slide。
第 1 轮 · 宽泛提问

1只说「做个轮播」，AI 交出的作业

我的提示词

帮我用 Swiper 做一个图片轮播，容器 id 是 wySw4，要能自动播放，底部有圆点分页，效果做得炫一点。

AI 的回答（代码）

new Swiper('#wySw4', {
  autoplay: true,
  pagination: { el: '.swiper-pagination' },
  effect: 'fade'
});

问题：四条需求只中了一条半

  • 缺无缝循环：没有 loop:true，翻到最后一张就停住。
  • 缺 3.2 秒：autoplay:true 走默认 3000ms，且默认 disableOnInteraction:true，手动一拖自动播放就永久停了。
  • 缺可点击：pagination 没写 clickable:true，圆点只能看不能点。
  • 效果答错：写了 fade（淡入淡出），要求的是 cube。
第 2 轮 · 需求拆成可判定条件

2把「炫一点」换成四个可验证的判断标准

我的提示词（第二轮）

用本地 Swiper 11 的 Swiper('#wySw4', {…}) 写配置，只输出配置对象，逐条满足：
① 无缝循环：开启 loop，首尾相接；
② 自动翻页间隔 3200 毫秒，并且手动拖动 / 点击箭头 / 点击圆点之后自动播放不停止；
③ 分页器用圆点样式，允许点击跳页；
④ 初始效果必须是 cube，不要 slide / fade，并给出 cubeEffect 的阴影参数。
每条需求后面用注释标出对应选项，方便我逐条核对。

AI 的回答（最终配置）

const zq_wySw4 = new Swiper('#wySw4', {
  effect: 'cube',                    // ④ 初始 cube
  loop: true,                     // ① 无缝循环
  autoplay: {
    delay: 3200,                   // ② 3.2 秒
    disableOnInteraction: false // ② 手动后不停止
  },
  pagination: {
    el: '.zq_pagination',
    clickable: true            // ③ 圆点可点击
  },
  cubeEffect: { shadow: true, slideShadows: true, shadowOffset: 18, shadowScale: 0.94 },
  speed: 700,
  grabCursor: true
});

这一轮补上的关键点

  • 把「自动播放」写成 数值 + 行为：delay:3200 与 disableOnInteraction:false，一句话同时锁住时长和不中断。
  • 把「炫一点」这种形容词换成 枚举值 'cube'，AI 没有解释空间。
  • 要求 AI 逐条加注释，代码交回来能直接对着需求验收，而不是靠肉眼猜哪行对应哪条。
验证 · 真机逐项点过

3四条需求的验证结果

需求验证动作结果一句话结论
无缝循环 连续点右箭头翻到第 5 张，再点一次 通过 第 5 张之后直接回到第 1 张，中间没有空白页。
3.2 秒自动翻页 不操作，掐表观察两次切换 通过 每次约 3.2 秒切换一张，与 delay:3200 一致。
手动后不停止 拖动一次并点箭头，然后静置观察 通过 手动操作后仍继续自动切换，页面上的切换计数持续增长。
圆点可点击 直接点第 1 个和第 4 个圆点 通过 点击后立即跳到对应页，圆点高亮同步变化。
初始 cube 效果 刷新页面观察首屏切换动画 通过 首屏切换即为立方体翻转，带阴影，不是平移或淡入。

4答辩准备

Q1：你的第一版提示词漏掉了哪个需求？
漏得最彻底的是 cube——我用「炫一点」代替了具体效果名；其次是自动播放的时长和「手动后不停止」这层行为，以及分页器的可点击性、循环开关，都属于我以为 AI 会默认做好、实际并不会的部分。
Q2：你是怎么在第二轮里「说清楚」的？
把形容词全部换成可判定的条件：效果写枚举值 cube，时长写毫秒数 3200，行为写选项 disableOnInteraction:false，并要求每条需求用注释标注对应选项。这样交回来的代码可以直接逐条验收。
Q3：AI 第一次给的代码错在哪？
一是效果写成了 fade，与要求的 cube 相反；二是 autoplay:true 用默认值，既不是 3.2 秒，又会在用户交互后永久停止；三是没有 loop 和 clickable，循环和点分页两项需求直接落空。
